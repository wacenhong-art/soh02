# 原论文协议救援实验报告

## 结论先行

复刻失败的首要原因已确认：旧流程把论文的“基于当前循环可观测HF直接估计”实现成了测试阶段递归预测STL分量，误差逐循环累积。改成直接HF窗口后，B0018的SCF-GAN增强CNN由旧完整G-MTC中位RMSE 5.1367改善到RMSE 1.6476、MAE 1.1094、MAPE 1.4727%、R² 0.9221。

但是，完整STL–TimesNet/iTransformer–Attention Bi-LSTM在严格前20%标签协议下仍未复现：RMSE 13.6298、R² -4.3282。该负结果已保留，不得宣称论文数值复现。

## 已执行协议

- B0018共128个有效循环，前25个循环（20%取整）构成目标小样本前缀。
- CNN/LSTM/Transformer检查点在前缀内以前20圈拟合、后5圈验证；第25圈以后为已经反复接触的开发评估集。
- 完整G-MTC使用DatasetID 0–4训练、DatasetID 5做合成轨迹验证；第25圈以后只在模型冻结后评估。
- 每个输入窗口以当前循环HF结束；不输入SOH/STL真值，不递归反馈预测SOH或预测分量。
- 所有窗口按DatasetID和连续Cycle独立构造，未跨轨迹拼接。
- 这些结果是开发评估，不是新的、未接触确认性测试。

## 完整G-MTC失败定位

- Trend预测单独RMSE 3.4711、R² 0.6544，长期斜率不足。
- PredTrend+PredSeasonal+PredResidual直接相加RMSE 9.4310。
- Seasonal在后期分布外外推到约1–9个百分点，而训练季节项接近零，造成严重尺度漂移。
- Attention融合进一步扩大误差至RMSE 13.6298；验证损失0.0484却无法代表后80%外推性能。
- 继续调整同一B0018测试曲线会构成测试集调参，因此本轮停止自动试错。

## 论文内部与实现信息边界

论文明确目标前20%、生成5套HF数据，但没有公开源码，也未完整披露比较模型宽度、STL边界、合成轨迹SOH配对方式、融合误差特征在推理时的可获得方式。论文Table 6列B0005、B0006和B0018，不列B0007；正文又提到B7，存在报告不一致。严格防泄漏实现不保证能达到论文数值。

## 当前唯一可信的下一步

1. 将B0018直接CNN 1.6476冻结为“协议修复检查点”，不要称为最终G-MTC。
2. 若必须继续追求论文0.9123，需要作者源码或作者确认其划分、合成SOH和融合9维误差特征；否则无法区分未披露工程细节与潜在数据接触。
3. 若目标转为可写创新论文，应预注册一个新的未接触外层电池；在验证集上只比较同一直接G-MTC的Original与Trend monotonic/smooth/both，测试只运行一次。
4. 不再要求独立Transformer必须最好。论文Table 6中B0018的LSTM RMSE 3.4921本就优于Transformer 3.8945；论文主张最好的是Developed method。
